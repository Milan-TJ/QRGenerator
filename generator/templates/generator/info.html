🧭 QR Code Generator API Documentation

You can use the QR Code Generator API to create QR codes programmatically from your own applications or scripts.

📍 Base URL

  {{ request.scheme }}://{{ request.get_host }}/api/generate/

📮 HTTP Method

POST – accepts JSON payload.

📦 Request Body (JSON)

  {
      "data": "https://example.com",
      "box_size": 10,
      "border": 4,
      "error_correction": "M",
      "output_format": "PNG"
  }
  • data – (required) Text or URL to encode in the QR.
  • box_size – (optional, int) Size of each QR box (default: 10).
  • border – (optional, int) White border thickness (default: 4).
  • error_correction – (optional) One of L, M, Q, H (default: M).
  • output_format – (optional) PNG, JPEG, or SVG (default: PNG).

🔧 Example (using curl)

  curl -X POST "{{ request.scheme }}://{{ request.get_host }}/api/generate/" \
  -H "Content-Type: application/json" \
  -d '{"data":"https://example.com","output_format":"SVG"}' \
  --output qrcode.svg

📤 Response

The API returns a binary file of the generated QR code in the requested format. You can download it directly or render it in your frontend app.

⚙️ Example Response Headers

  Content-Type: image/svg+xml
  Content-Disposition: attachment; filename="qrcode.svg"

💡 Tips

  • To generate a PNG instead, set "output_format":"PNG".
  • You can embed this API in JavaScript, Python, or Node scripts.
  • When deploying, your base URL changes automatically (the above block always updates).
